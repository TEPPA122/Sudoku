# Судоку з термометрами

Інтерактивна вебгра "Судоку з термометрами" - класичне судоку 9×9 з додатковою механікою термометрів.

## Про гру

**Судоку** - це логічна головоломка, де потрібно заповнити сітку 9×9 числами від 1 до 9 так, щоб:
- Кожна цифра зустрічалася лише один раз в кожному рядку
- Кожна цифра зустрічалася лише один раз в кожному стовпці
- Кожна цифра зустрічалася лише один раз в кожному блоці 3×3

**Термометри** - це додаткові обмеження в вигляді послідовностей сусідніх клітинок, де значення мають збільшуватися від початку (колба) до кінця.

## Як запустити гру

Проєкт використовує **ES modules** (`type="module"`). При відкритті `index.html` через `file://` браузер може блокувати підключення скриптів. Рекомендований спосіб:

1. Запустіть локальний сервер із кореня репозиторію:
   ```bash
   cd Sudoku && python3 -m http.server 8080
   ```
2. Відкрийте в браузері: `http://localhost:8080`

Гра за замовчуванням стартує з середньою складністю.

## Керування грою

### Введення чисел
- **Кліком мишкою**: Клікніть на порожню клітинку та виберіть число з панелі або натисніть кнопку
- **З клавіатури**: Виберіть клітинку та натисніть цифру 1-9
- **Навігація**: Використовуйте стрілки ↑↓←→ для переміщення між клітинками

### Видалення чисел
- Натисніть кнопку **"Очистити (Delete)"** або клавішу **Delete/Backspace**

### Кнопки керування
- **Нова гра** - почати нову гру з вибраною складністю
- **Перевірити** - перевірити правильність розв'язання
- **Очистити поле** - видалити всі введені числа

### Складність
- **Легка** - 30 порожніх клітинок
- **Середня** - 45 порожніх клітинок (за замовчуванням)
- **Складна** - 55 порожніх клітинок

## Особливості реалізації

### Логіка судоку (`js/sudoku.js`)
- `generateSolution()` - генерує правильне судоку 9×9
- `createGame(difficulty)` - створює ігрову дошку з прихованими числами
- `checkCell()` / `checkAll()` - перевіряє наявність помилок

### Логіка термометрів (`js/thermometers.js`)
- `generateThermometers()` - генерує випадкові термометри
- `checkThermometer()` / `checkAllThermometers()` - перевіряє дотримання правил
- Термометри генеруються тільки там, де числа вже зростають у правильному судоку

### Керування грою (`js/game.js`)
- `GameController` - основний клас, який керує всіма аспектами гри
- `drawThermometers()` - малює термометри на SVG
- `handleKeyboard()` - обробляє введення з клавіатури
- `checkForErrors()` - перевіряє помилки в реальному часі
